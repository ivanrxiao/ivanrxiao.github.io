# ivanrxiao.github.io

Personal academic website of Runhua (Ivan) Xiao: https://ivanrxiao.github.io

The site is a single static page with no build step. index.html is the page, photo.jpg is the portrait, and Runhua_Xiao_CV.pdf is the CV linked from the page. The .nojekyll file tells GitHub Pages to serve these files as they are.

To update the site, replace a file and commit to the master branch. GitHub Pages republishes it within a few minutes.
